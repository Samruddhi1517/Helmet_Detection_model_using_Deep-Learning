#  ⛑ Helmet Detection Model using Deep Learning

## 📌 Project Overview


The Helmet Detection Model using Deep Learning is a real-time safety monitoring system developed using YOLOv8, OpenCV, Flask, and Deep Learning techniques. The project detects whether a person is wearing a helmet or not through images, videos, and live webcam streams.

The system uses a pretrained YOLOv8 object detection model to identify helmets with high accuracy and display results using bounding boxes and confidence scores in real time. This project can be used in traffic monitoring, construction site safety, and surveillance systems to improve safety compliance and reduce accidents.


---

## 🚀 Features

* ✅ Real-time helmet detection using webcam
* ✅ Helmet detection in images
* ✅ Helmet detection in videos
* ✅ Flask web application integration
* ✅ Deep Learning-based object detection
* ✅ YOLOv8 pretrained model support
* ✅ Automatic bounding box visualization

## ⚙️ Installation

### Step 1: Clone Repository

```bash
git clone https://github.com/Samruddhi1517/Helmet_Detection_model_using_Deep-Learning.git
```

### Step 2: Move to Project Folder

```bash
cd Helmet_Detection_model_using_Deep-Learning
```

### Step 3: Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

```bash
python app.py
```

After running, open:

```bash
http://127.0.0.1:5000
```
